# 📊 Guide Utilisateur - Surveillance de Votre Santé Respiratoire

## 🏥 Qu'est-ce que la surveillance des indicateurs vitaux ?

L'application E-Santé 4.0 - DALYS vous permet de surveiller en temps réel trois paramètres essentiels de votre santé respiratoire. Ces mesures vous aident à comprendre votre état de santé et à prendre les bonnes décisions pour votre bien-être.

## 💾 Comment fonctionne l'affichage des données dans l'application

### 🔄 Données actuellement utilisées
**Important à savoir :** Pour le moment, l'application utilise des **données de démonstration** (simulées) pour vous permettre de découvrir toutes ses fonctionnalités. Ces données de test :

- **Se mettent à jour automatiquement** toutes les 10 secondes
- **Simulent des valeurs réalistes** correspondant à différents états de santé
- **Permettent de tester** toutes les fonctionnalités sans équipement médical
- **Reflètent exactement** ce que vous verrez avec de vraies mesures

### 🌐 Évolution future : Capteurs connectés
Dans les prochaines versions, l'application pourra se connecter à :

- **Oxymètres de pouls Bluetooth** pour la saturation en oxygène (SpO₂)
- **Capteurs respiratoires Wi-Fi** pour la fréquence respiratoire
- **Débitmètres de pointe connectés** pour mesurer votre capacité pulmonaire


### 📱 Ce que vous voyez à l'écran
L'affichage des données fonctionne de la manière suivante :

1. **Mise à jour en temps réel** : Les valeurs se rafraîchissent automatiquement sans que vous ayez besoin de recharger l'application

2. **Cartes colorées** : Chaque paramètre (SpO₂, respiration, débit) est affiché dans une carte avec :
   - La valeur numérique actuelle
   - L'unité de mesure (%, bpm, L/min)
   - Une couleur d'alerte (vert, orange, rouge)
   - Une icône représentative

3. **Graphiques d'évolution** : Les dernières mesures sont tracées sur des courbes pour voir l'évolution dans le temps

4. **Indicateur de risque global** : Un cercle coloré vous donne une vision d'ensemble de votre état

### ✅ Pourquoi ces données simulées sont utiles
Même si les données sont actuellement simulées, elles vous permettent de :

- **Apprendre à utiliser** l'interface avant d'avoir des capteurs
- **Comprendre les seuils** d'alerte et les couleurs
- **Tester la saisie manuelle** de mesures
- **Voir comment réagir** selon différents scénarios
- **Vous familiariser** avec les graphiques et statistiques

**Rassurez-vous** : Le fonctionnement de l'application sera exactement identique avec de vraies données médicales. Seule la source des données changera !

## 🔍 Les trois indicateurs que vous pouvez suivre

### 1. 💓 Saturation en oxygène (SpO₂)
**Qu'est-ce que c'est ?**
- Mesure le pourcentage d'oxygène dans votre sang
- Valeurs normales : 95% à 100%
- **Affiché en pourcentage** avec une icône cœur

**Pourquoi c'est important ?**
- Une saturation basse peut indiquer des problèmes respiratoires
- Vous aide à détecter précocement une détresse respiratoire

### 2. 🫁 Fréquence respiratoire
**Qu'est-ce que c'est ?**
- Nombre de respirations par minute
- Valeurs normales : 12 à 20 respirations par minute
- **Affichée avec l'unité "bpm"** (battements par minute)

**Pourquoi c'est important ?**
- Une respiration trop rapide peut signaler une gêne
- Permet de surveiller votre rythme respiratoire au repos

### 3. 🌪️ Débit de pointe (PEF)
**Qu'est-ce que c'est ?**
- Mesure la force avec laquelle vous pouvez expirer l'air de vos poumons
- Valeurs normales : 350 à 500 L/min
- **Affiché en L/min** (litres par minute)

**Pourquoi c'est important ?**
- Indique la capacité de vos poumons
- Utile pour les personnes asthmatiques ou avec des problèmes pulmonaires

## 🎨 Comment lire les couleurs d'alerte

L'application utilise un système de couleurs simple pour vous informer rapidement :

- 🟢 **VERT** = Tout va bien ! Vos valeurs sont normales
- 🟡 **ORANGE** = Attention, surveillez cette valeur
- 🔴 **ROUGE** = Alerte ! Cette valeur nécessite votre attention

## ❓ Où se trouve le bouton d'action ?

### 🔍 Localisation du bouton "Nouvelle mesure"

Le **bouton d'action principal** de l'application est situé **en bas à droite** de votre écran. Voici comment le reconnaître :

- **Forme** : Bouton oval/arrondi qui "flotte" au-dessus du contenu
- **Couleur** : Bleu médical (couleur principale de l'application)
- **Icône** : Cercle avec un symbole "+" à l'intérieur
- **Texte** : Affiche le texte **"Nouvelle mesure"**
- **Position** : Toujours visible en bas à droite, même quand vous faites défiler la page

> 📍 **Important** : Ce bouton reste fixé en bas à droite de l'écran et ne disparaît jamais, vous permettant d'ajouter une mesure à tout moment, quelle que soit la section du dashboard que vous consultez.

### 🎯 À quoi sert ce bouton ?

Lorsque vous appuyez sur le bouton "Nouvelle mesure", une fenêtre s'ouvre vous permettant de :
- Saisir manuellement vos paramètres vitaux (SpO₂, respiration, débit de pointe)
- Indiquer vos symptômes actuels
- Enregistrer ces informations pour un suivi continu

## 📱 Comment utiliser cette fonctionnalité

### Étape 1 : Ouvrir l'application
- Lancez l'application E-Santé 4.0 sur votre téléphone
- Le tableau de bord s'affiche automatiquement avec vos dernières mesures

### Étape 2 : Lire vos indicateurs
- Regardez les trois cartes principales affichées
- Chaque carte montre une valeur avec sa couleur d'état
- L'indicateur de risque global vous donne une vue d'ensemble

### Étape 3 : Ajouter une nouvelle mesure
- **Localisez le bouton d'action** : Cherchez le bouton oval **"Nouvelle mesure"** qui flotte en bas à droite de votre écran (bouton rond avec une icône +)
- **Appuyez sur ce bouton** pour ouvrir le formulaire de saisie
- Entrez vos valeurs manuellement (si vous avez un appareil de mesure)
- Sélectionnez vos symptômes si vous en ressentez
- Appuyez sur **"Enregistrer"** pour sauvegarder vos données

> 💡 **Astuce** : Le bouton "Nouvelle mesure" est toujours visible en bas à droite de l'écran, même lorsque vous faites défiler la page. Il a une couleur bleue distinctive et affiche une icône de cercle avec un plus (+).

## 💡 Conseils pour une utilisation optimale

### 📋 Bonnes pratiques
- **Mesurez régulièrement** : Idéalement à la même heure chaque jour
- **Restez au repos** : Prenez vos mesures au calme, après 5 minutes de repos
- **Notez vos symptômes** : Ajoutez toux, fatigue, essoufflement pour un suivi complet
- **Suivez les tendances** : Regardez l'évolution plutôt que les valeurs isolées

### ⚡ Quand mesurer
- **Le matin** au réveil (mesure de référence)
- **Avant les repas** (estomac vide)
- **En cas de symptômes** respiratoires
- **Avant et après l'effort** (si autorisé par votre médecin)

### 🔄 Mise à jour automatique
- Les données se rafraîchissent automatiquement
- Pas besoin de fermer et rouvrir l'application
- L'historique se constitue progressivement

## ❓ Questions Fréquentes (FAQ)

### Où se trouve le bouton pour ajouter une nouvelle mesure ?
Le bouton **"Nouvelle mesure"** est un bouton oval bleu situé en **bas à droite de l'écran**. Il comporte une icône de cercle avec un "+" et reste visible en permanence, même lorsque vous faites défiler la page vers le haut ou le bas.

### Comment ajouter mes propres mesures ?
1. Appuyez sur le bouton **"Nouvelle mesure"** en bas à droite
2. Remplissez les champs avec vos valeurs mesurées
3. Sélectionnez vos symptômes éventuels
4. Appuyez sur **"Enregistrer"**

### Le bouton d'action est-il toujours visible ?
Oui ! Le bouton "Nouvelle mesure" est un bouton flottant (FloatingActionButton) qui reste fixe en bas à droite de l'écran, quelle que soit votre position dans le dashboard.

### Que faire si je ne vois pas le bouton ?
- Assurez-vous que l'application est complètement chargée
- Vérifiez en bas à droite de votre écran
- Le bouton devrait être au-dessus du contenu avec une couleur bleue distinctive
- Essayez de faire défiler légèrement la page pour vérifier sa présence

### Puis-je ajouter des mesures à tout moment ?
Oui ! Le bouton "Nouvelle mesure" est accessible à tout moment depuis le dashboard principal. Vous pouvez ajouter autant de mesures que nécessaire pour un suivi optimal de votre santé.
